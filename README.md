# Notes Together

### **Collaborative note-taking service.**

**Notes Together** — веб-приложение для создания, организации и совместного использования заметок. 
Проект предназначен для удобного хранения личной информации и совместной работы с заметками нескольких пользователей.
Запускается локально с использованием Docker.

## Основные возможности

- **Управление заметками:** создание, просмотр, редактирование и удаление заметок.
- **Организация заметок:** использование тегов, цветового оформления, поиска и сортировки.
- **Архивация и корзина:** возможность архивировать заметки, перемещать их в корзину и восстанавливать. Состояние архива и корзины индивидуально для каждого пользователя.
- **Совместный доступ:** приглашение других пользователей к заметкам, просмотр списка участников и управление их доступом.
- **Ролевая модель:** поддержка ролей читателя и редактора, определяющих доступные действия с заметкой.
- **Аутентификация и авторизация:** регистрация пользователей и защищённый доступ к данным с использованием JWT.

## Технологический стек

Проект разработан с использованием следующих технологий:

- **Frontend:** Vue 3, TypeScript, Vite, Tailwind CSS 4, Pinia, Vue Router.
- **Валидация форм:** VeeValidate, Zod.
- **UI-компоненты:** Lucide, Verte.
- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic.
- **База данных:** PostgreSQL.
- **Миграции базы данных:** Alembic.
- **Контейнеризация и управление окружением:** Docker, Docker Compose (для запуска PostgreSQL).
- **Тестирование:** Pytest, FastAPI TestClient.

## Архитектура проекта

Приложение построено на основе клиент-серверной архитектуры и состоит из трёх основных компонентов:

- **Frontend** — пользовательский интерфейс, реализованный на Vue 3. Отвечает за взаимодействие с пользователем и отправку запросов к серверу.
- **Backend** — серверная часть на FastAPI. Обрабатывает HTTP-запросы, выполняет бизнес-логику, проверяет права доступа и взаимодействует с базой данных.
- **База данных** — PostgreSQL. Используется для хранения информации о пользователях, заметках, тегах и связях между ними.

Взаимодействие между Frontend и Backend осуществляется через REST API. Для защиты пользовательских ресурсов применяется JWT-аутентификация.

Для запуска PostgreSQL используется Docker Compose.


## Установка и запуск
### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd notes_together
```


### 2. Первичная настройка Backend

### !Если Python не установлен в IDE, загрузите его перед запуском!

### *Инструкция для WebStorm*
1. Перейти в настройки: `File` - `Settings` (Ctrl + Alt + S).
2. Выберите пункт `Plugins` и установите "Python Community Edition".
3. Дождитесь окончания загрузки и перезапустите IDE.

Перейдите в директорию Backend:

```bash
cd backend
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его (Windows PowerShell):

```powershell
.venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

### 3. Настройка окружения

Для работы Backend необходимо создать файл `backend/.env` с параметрами подключения к PostgreSQL.

Для удобства были созданы 2 шаблона .env файла с припиской ".example", содержащие названиями необходимых данных и базовыми значениями. 

##### После завершения настройки данных файлов переименуйте их в файлы `.env` в директории `/backend` и в `.env.local` в директории `/frontend`.

### `backend/.env`

Файл должен содержать следующие переменные:

- `POSTGRES_USER` - имя пользователя PostgreSQL;
- `POSTGRES_PASSWORD` - пароль пользователя;
- `POSTGRES_HOST` - адрес базы данных;
- `POSTGRES_PORT` - порт подключения;
- `POSTGRES_DB` - название базы данных.

Для настройки JWT-аутентификации необходимо указать следующие параметры:

- `SECRET_KEY` - секретный ключ для подписи JWT-токенов. Генерируется один раз с помощью модуля secrets из стандартной библиотеки Python:

Для быстрой генерации выполните следующую команду в консоли с активированным окружением:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Полученное значение необходимо записать в SECRET_KEY. Ключ должен оставаться неизменным между запусками приложения.

- `ALGORITHM` — алгоритм подписи JWT-токенов (по умолчанию HS256).
- `EXPIRE_MINUTES` — время действия токена в минутах (по умолчанию стоит 30 минут).

Файл `.env` содержит конфиденциальные данные и не должен добавляться в Git.

### 4. Запуск базы данных

Откройте второй терминал (консоль).
Из корневой директории проекта выполните:

```bash
docker compose --env-file backend/.env up -d
```

Для проверки состояния контейнера:

```bash
docker compose --env-file backend/.env ps
```

Подготовьте БД - примените миграции базы данных:

```bash
cd backend
alembic upgrade head
```

Запустите сервер:

```bash
python -m uvicorn app.main:app --reload
```

После запуска Backend документация API будет доступна по адресу:

[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

### 5. Запуск Frontend

Откройте отдельный терминал и перейдите в директорию Frontend:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Запустите сервер разработки:

```bash
npm run dev
```

Адрес запущенного приложения будет указан в терминале.

## Запуск тестов Backend

Из директории `backend` с активированным виртуальным окружением выполните:

```bash
python -m pytest
```
